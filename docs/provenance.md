# Asset provenance

## Original generic geometry

All 39 GE_ collection assets in `library/Generic_Experimental_Optics.blend` are authored procedurally in `scripts/build_generic_library.py`, using generic primitives and explicit illustrative parameters. No manufacturer meshes, STEP files, traced surfaces or manufacturer textures are distributed in this package. `docs/assets.json` records each asset's parameters and origin convention.

These models are inspired by common laboratory optomechanics, including equipment manufactured by Thorlabs. This is an acknowledgment of inspiration, not a claim of affiliation, endorsement, permission to reuse manufacturer CAD, or certified product compatibility. Original code is MIT; original models and documentation are CC BY 4.0.

Catalogue display instances normalize sizes for legibility; source assets retain meter units. The catalogue and example hardware renders were regenerated from the generic library. Materials and mounting arrangements are illustrative; these are visualization assets, not manufacturing designs or optical simulations.

## Supplied reference images

The SLM hologram and CCD intensity panels retain their existing rights. Permission to redistribute these two images was confirmed by the contributor. See [their provenance](../examples/paper-setup/reference-images/README.md). They are supplied data imagery, not simulated results. The paper's 2D schematic motivated this later Blender reconstruction; the paper does not contain these models.
